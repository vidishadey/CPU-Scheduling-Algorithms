Algorithm Descriptions & Formulas

FCFS (First Come First Serve):

Processes are executed in order of arrival.

SJF (Shortest Job First):

The process with the shortest burst time is selected first.

SRTF (Shortest Remaining Time First):

The process with the shortest remaining time is selected.

Round Robin (RR):

Each process gets CPU time according to the time quantum.

Priority Non-Preemptive:

The available process with the highest priority is selected.

Priority Preemptive:

The process with the highest priority can interrupt the current process.

Standard CPU Scheduling Formulas:
  • Turnaround Time (TAT) = Completion Time (CT) - Arrival Time (AT)
  • Waiting Time (WT) = Turnaround Time (TAT) - Burst Time (BT)
  • Average Waiting Time = Total WT / Number of Processes
  • Average Turnaround Time = Total TAT / Number of Processes
